AI Robot Agent

Language → structured plan →
deterministic robot action.

The LLM operates at task-planning level only. All output is validated against a safety schema before any ROS 2 action is dispatched. The LLM can never directly write to /cmd_vel or any actuator topic.

Request Flow
🎤 "Find the red box and take me to it."
↓
🧠 LLaMA 3.1 8B (via ollama)
Produces structured JSON task plan
↓
✅ Task Validator
JSON schema · action whitelist · safety check
↓
🎯 Action Dispatcher
find_object() → navigate_to() → verify()
↓
🤖 ROS 2 Action Clients → Nav2 / Perception
↓
✅ "I found the red box. Arrived at (3.2, 1.4)."
Agent Tools
navigate_to(x, y, theta)Navigate to map coordinates
find_object(class_name)Search and locate object
follow_person(person_id)Person-following behavior
dock()Navigate to charging station
patrol(waypoints)Sequential waypoint patrol
inspect(object_id)Navigate to + visually inspect
query_world(query)Query world model
report_status()Return system health
e_stop()Emergency halt (bypasses LLM)
Safety Rules
🚫 LLM output is never written to /cmd_vel
✅ All task plans validated against JSON schema
✅ Velocity limits enforced in C++ controller
✅ Proximity guard: LiDAR < 0.15m → hard stop
✅ Watchdog: all critical nodes heartbeat at 1Hz
✅ E-stop is hardware-level, bypasses all software
